# **T0 — Scaffold, CLI, fixtures**

- Keep the skeleton modules. You may add `src/app.rs` for App state, update and view, keeping `main.rs` thin.
- CLI: `marqed-spike <path> [--repeat N] [--bench K]`.
  - A non-UTF-8 or unreadable file prints an action-phrased error and exits non-zero.
  - `--repeat` joins N copies with `"\n\n"`.
- Fixture `fixtures/spike.md` must contain at least:
  - an H1; an H2 containing `**bold**`; `### Title ###` (closing sequence); an empty `##` line; a heading indented by 3 spaces;
  - a paragraph with `**bold**`, `*italic*`, `***both***`, `**a** **b**`, and an unclosed `**x`;
  - a 3-line paragraph (internal newlines) with bold spanning a line break;
  - a paragraph long enough to wrap at 800 px;
  - a Unicode paragraph: `é`, `e\u{301}`, `👍🏽` and CJK, with bold around some of them;
  - literal `\n` and `C:\new\path`; the escape `\*not bold\*`;
  - runs of 2 or more blank lines; a whitespace-only line;
  - a list and a fenced code block (both Raw); a setext heading (Raw).
- Also `fixtures/no_trailing_newline.md` and `fixtures/empty.md`.
- The app shows the raw text in a stock `text` widget inside a `scrollable`.

**Acceptance:** `cargo run -- fixtures/spike.md` displays the file; all three fixtures load without panicking.
