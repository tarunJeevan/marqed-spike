# **T6 — Geometry, cursor, keys, click (C-8 geometry, C-6, C-11 keys).**

- Headless geometry tests build concrete paragraphs directly from a wrapped, multi-line, mixed-size projection and check:
  - every visible boundary round-trips `vis → point → vis`;
  - a hit on hard line *k* returns a byte on line *k*;
  - rows are y-ordered;
  - EOL and empty-segment handling.
- Wire in cursor drawing, Normal `h`/`l`, `i`/`Esc`, the F1–F5 toggles and click (F4).
