# **T3 — Projection (C-5, C-6)**

- `proptest` over generated documents. The alphabet is the atoms `a`, `é`, `e\u{301}`, `👍🏽`, ` `, `*`, `_`, `#`, `\n`, `\`, `n`.
- Generate random valid cursors in both modes, under all four policies. Properties:
  - **P1** — the visible-byte round trip `vis → src → vis` is the identity;
  - **P2** — `src_to_vis` is monotone (non-decreasing);
  - **P3** — the I-6 frame invariant holds;
  - **P4** — the run table covers the segment range exactly for every reveal set;
  - **P5** — interleaving the runs reconstructs the source bytes exactly.
- Plus literal tests on the fixture lines.
